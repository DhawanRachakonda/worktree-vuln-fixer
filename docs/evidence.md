## Not proven

- A real Black Duck or Coverity export (the samples are hand-made); the Coverity subject with Copilot as the agent.
- Copilot as the agent on the Java `shop` audit fixture (Copilot audited the React fixture above, and an earlier Node-based one, see `engine/docs/spec-coverage.md`).
- Which of Claude Code's and Copilot's verdicts on the React lead is right (neither ran the code).
- `--allow-all-tools` / `bypassPermissions` (refused by this environment's safety check); macOS; `appmod init` end to end (it changes the machine).
- The engine's live NATS tests on Linux outside GitHub's runner: they start their NATS server in a Docker container (`NatsTestServer`); they passed on Windows with Docker Desktop and, in the `live` job of `.github/workflows/ci.yml`, on GitHub's Ubuntu runner in pull request 1 ([`evidence/ci-pull-request-1.txt`](evidence/ci-pull-request-1.txt); its first run failed on one flaky test of mine, fixed, then all three jobs passed).
- **Any hosted git service** (GitHub, GitLab, Bitbucket, cloud or on-premises), `gh`, `glab` and the pull-request templates in `engine/docs/publishing.md`: pushes and the pull-request command were run against a local bare repository and a stand-in program only. Credentials that need a browser or a prompt were not run either.
- A person typing the answer to the `appmod init` source-branch question at a real terminal (the tests read the answer from a file).
